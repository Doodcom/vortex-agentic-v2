## Bug fixes (in chronological order)

| Symptom | Root cause | Fix |
|---|---|---|
| 500 error on chat | `nomic-embed-text` selected as chat model (it's embed-only) | Filter embed models from chat dropdown |
| Tool calls hanging on qwen3:14b | Qwen3 thinks by default; thinking interleaved with tool calls | Force `/no_think` for Qwen3 in agentic mode |
| Tool calls hanging on qwen2.5-coder | Doesn't support Ollama's native tool API | Added back to NO_TOOL_MODELS (text-tool fallback) |
| Image gen stuck at 0% | `comfy-aimdo` 0.3.0 had broken 1-arg `HostBuffer` API | Upgraded to 0.4.4 (proper 4-arg signature) |
| WAN: OOM | 1024×1024 + no block swap | Forced 832×480 + block-swap 30 + comfyPurge before gen |
| WAN: VAE precision required | Schema said optional, runtime required | Pass `precision: "bf16"` explicitly |
| WAN: `None > int` crash | Wrapper's `vace_blocks_to_swap` defaulted to None, compared with `> 0` | Pass `vace_blocks_to_swap: 0` explicitly |
| WAN: image_embeds required | Sampler requires it even in T2V | Added `WanVideoEmptyEmbeds` node |
| FaceDetailer: missing SAM fields | Schema mismatch — runtime requires 7 SAM-related fields | Pass neutral SAM defaults |
| FaceDetailer: `could not find MARK` | `face_yolov8m.pt` was a 9-byte 404 HTML response | Downloaded the real 50MB model from Bingsu/adetailer |
| HEIC upload silently failed | `String.fromCharCode(...new Uint8Array(buf))` blew the JS call stack on files > 65KB | Switched to `FileReader.readAsDataURL` |
